# Button

This Gaudi owner includes **button**, with **61 practical examples**.

Buttons use a compact height scale: `xs` 24px, `sm` 28px, `md`/`default` 32px, and `lg` 36px. Icon buttons use the matching `icon-xs`, `icon-sm`, `icon`, and `icon-lg` sizes. Default inputs and selects also use 32px; match the size when placing controls in the same row. See the **With Controls** story for input, select, and number-field compositions.

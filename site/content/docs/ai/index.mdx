---

Gaudi ships everything an agent needs to use it correctly, generated from the same sources as the components (owner docs, READMEs, the story catalogue, the coverage manifest, tokens, the icon registry and the package exports), so it cannot drift.

| Piece | Where | Ships in the npm package |
| --- | --- | --- |
| Metadata | `ai/components.json`, `blocks.json`, `tokens.json`, `icons.json`, `setup.json`, `exports.json` | yes |
| LLM docs | `llms.txt`, `llms-full.txt`, `docs/llm/<id>.md` | `llms*.txt` yes |
| Agent skill | `skills/gaudi-design-system/SKILL.md` | yes |
| CLI / MCP | `bin/gaudi-ds.mjs`, `cli/` | yes |
| Registry | `registry.json`, `public/r/<name>.json` | repository only until hosted |

Ask your agent to “design a sortable list for a phone.” The packaged `gaudi-design-system` skill looks up Gaudi’s Sortable component and its local examples, then consults a relevant bookmarked publisher such as beUI for touch interactions. You can name a preferred publisher or ask it to work offline. Browse the bookmarks on the [Credits page](/docs/credits#useful-resources).

## Install in a project

From a project that already depends on `@gaudi/design-system`, run the command for your client.

```sh
pnpm exec gaudi-ds skills install --agent codex
pnpm exec gaudi-ds skills install --agent claude
```

| Agent | Installed to |
| --- | --- |
| `claude` | `.claude/skills/gaudi-design-system/SKILL.md` and `references/` |
| `cursor` | `.cursor/rules/gaudi-design-system.mdc` (auto-attached for JS/TS/MDX) |
| `codex`, `opencode` | a managed section in `AGENTS.md` |
| `windsurf` | `.windsurf/rules/gaudi-design-system.md` |
| `vscode` | `.github/instructions/gaudi-design-system.instructions.md` |

Run the installer again after upgrading Gaudi to refresh the managed skill. To install from the DS checkout, use `node bin/gaudi-ds.mjs skills install --agent codex --dir ../my-app`.

An agent connected to the [Gaudi MCP server](/docs/ai/mcp) can read the skill with `get_agent_skill({})` and its component workflow with `get_agent_skill({topic: "component-design"})`. The same workflow ships in the package under `skills/gaudi-design-system/references/component-design.md`.

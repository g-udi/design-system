## Prose

Long-form content uses the `.prose` class from Gaudi's typography foundation: comfortable measure, a {'1.7'} line height and heading rhythm tuned for articles. This page is rendered inside `.prose`.

Use `Typography` and `typographyVariants` from the package root for headings, labels and descriptions in application UI, and the [fonts guide](/docs/getting-started/fonts) to load real families.

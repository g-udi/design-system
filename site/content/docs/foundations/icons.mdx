---
title: Icons
description: The icon registry behind Icon, plus brand marks and animated icons.
---

```jsx
import { Icon } from '@gaudi/design-system';

<Icon name='Info' size='md' color='primary' label='More information' />
```

Pass `label` when the icon carries meaning and `decorative` otherwise. Sizes: `xs`, `sm`, `md`, `lg`, `xl`, `2xl` or a number. Brand marks are separate entries such as `@gaudi/design-system/icons/brands/github`.

## This site

- Site layout inspired by [beUI](https://beui.dev) (for example its [project folder block page](https://beui.dev/components/blocks/project-folder)).
- Routing, MDX content, the search index and the table of contents by [Fumadocs](https://fumadocs.dev) (MIT).
- Built with [Next.js](https://nextjs.org) (MIT), [React](https://react.dev) (MIT) and [Tailwind CSS](https://tailwindcss.com) (MIT).
- Every component in the chrome (app shell, tabs, code blocks, command palette, menus, buttons) is [Gaudi](https://github.com/g-udi/design-system) itself.

## The design system

Gaudi's dependencies, adapted code, assets and inspirations are listed in its README: [Credits & acknowledgements](https://github.com/g-udi/design-system#credits--acknowledgements) and [Third-party notices](https://github.com/g-udi/design-system#third-party-notices).

Theme authoring credits go to [StyleGlide](https://www.styleglide.ai/themes), [tweakcn](https://tweakcn.com) and [shadcn/ui](https://ui.shadcn.com/themes); the AI setup is inspired by [reui](https://reui.io).

### Orbs

The orb visuals build on three MIT-licensed projects:

- [orb-ui](https://orb-ui.com) ([source](https://github.com/exprmntl/orb-ui)): the circle, bars, cloud and radial variants.
- [Thinking Orbs](https://libraries.dev/orbs) on libraries.dev ([source](https://github.com/Jakubantalik/Libraries.dev)): the activity orb.
- [VoiceOrbs](https://voiceorbs.vercel.app) ([source](https://github.com/amunozdev/voiceorbs)): the iridescent, mercury and waveform orbs.

## Useful resources

Component libraries, blocks and registries worth browsing alongside Gaudi:

- [React Bits](https://reactbits.dev): animated React components, text effects and backgrounds.
- [reui](https://reui.io): components, blocks and agent tooling for shadcn/ui.
- [shadcn.io](https://www.shadcn.io): community components, blocks and tools for shadcn/ui.
- [registry.directory](https://registry.directory): a directory of shadcn/ui registries.
- [Shadcnblocks](https://www.shadcnblocks.com): ready-made blocks for shadcn/ui.
- [shadcncraft](https://shadcncraft.com): shadcn/ui components and blocks.
- [Shadcn UI Kit](https://shadcnuikit.com): dashboards, templates and components.
- [shadcn/studio](https://shadcnstudio.com): components, blocks and a theme generator.
- [Skiper UI](https://skiper-ui.com): animated components for shadcn/ui.
- [cult/ui](https://www.cult-ui.com): animated components and blocks for shadcn/ui.
- [AI SDK Agents](https://www.aisdkagents.com): agent building blocks for the [AI SDK](https://ai-sdk.dev).

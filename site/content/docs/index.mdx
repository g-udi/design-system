Gaudi brings reusable React components, design foundations and practical interface patterns into one coherent system. It began with a blog and grew to support application interfaces: forms, data views, navigation, dialogs, dashboards and complete workflows, alongside rich editorial and MDX experiences.

The package is `@gaudi/design-system`; the source lives at [g-udi/design-system](https://github.com/g-udi/design-system).

## How this site is built

Every component, block, chart, chat and hook page is **generated from the design system's own metadata** (its `ai/components.json`, the pattern coverage manifest and the owner fixtures), so the docs cannot drift from the code. Each example renders the real fixture in an isolated frame, and its **Code** tab shows the same copyable source as Storybook, rewritten to public `@gaudi/design-system/...` imports.

## What belongs in Gaudi

- **Foundations:** shared tokens, typography, colours, icons, motion and accessibility conventions.
- **Components:** reusable controls and compositions, with variants and interaction states for real product use.
- **Patterns and blocks:** application shells, settings, onboarding, collections and editorial page sections.
- **Publishing:** post components, reading layouts and MDX primitives for blogs and other content experiences.

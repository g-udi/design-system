# Highlight

> MDX/Highlight · mdx · `@gaudi/design-system/mdx/Highlight`

Inline emphasis within article text.

## Import

```js
import Highlight from '@gaudi/design-system/mdx/Highlight';
// also: import { … } from '@gaudi/design-system/mdx';
```

Exports: `default`

## Props

| Name | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| `children` | `ReactNode` | — | no | Content composed from the exported parts. |

## Usage

```jsx
Use <Highlight>inline emphasis</Highlight> inside normal article prose.
```

## Accessibility

Highlighted text stays in the normal reading order; do not rely on color alone for meaning.

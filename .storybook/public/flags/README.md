# Sample flags

Country flags for the data-grid examples, served at `/flags/<iso-3166-alpha-2>.svg`
(for example `/flags/gb.svg`), so stories never load images from the network.

They were downloaded once, on 2026-10-02, from [Flagpedia's flagcdn](https://flagcdn.com/), whose
flag images are in the public domain. `es.svg` is the plain civil flag of Spain (red, yellow,
red; no coat of arms), drawn by hand to keep the asset small.

Codes shipped: at, au, br, ca, cz, de, es, fr, gb, ie, in, it, jp, kr, my, us. Add a file here
before using a new code in an example.
